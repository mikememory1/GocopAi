BACKEND LOGIC REQUIREMENTS
--------------------------------------------------

1. Auth
   - Implement signup, login, logout, password reset.
   - On signup:
     - Create user with default role `user`
     - Set initial credits (e.g. 50)
   - On login:
     - Update last_login_at

2. Role enforcement
   - Middleware/guards:
     - `/app/admin` → admin only
     - All `/app/*` → authenticated only
   - Redirect unauthenticated users to login.

3. Credits
   - Before each AI generation:
     - Check user credits
     - If insufficient → return error
   - After generation:
     - Deduct credits
     - Log in `ai_generations`

4. AI abstraction
   - Create a single backend module/function that:
     - Accepts: model_name, system_prompt, user_prompt, temperature, max_tokens
     - Uses environment variables for API keys (e.g. OPENAI_API_KEY, GROQ_API_KEY, etc.)
     - For now, implement with one provider (e.g. OpenAI) but structure it so it’s easy to swap.
   - All tools call this abstraction.

5. Quiz engine
   - Define quiz questions in a structured way (array/JSON in code).
   - Each question:
     - id
     - text
     - type
     - category
     - weight
     - options (if applicable)
   - On submit:
     - Validate answers
     - Compute category scores and overall score
     - Map score → stage
     - Call AI to generate personalised action plan:
       - Input: category scores, stage, business info (if available)
       - Output: structured plan (sections, bullet points)
     - Save to `quiz_results`
     - Return data to frontend.

6. Stripe integration
   - Create backend endpoints for:
     - Creating checkout session for subscription
     - Creating checkout session for credit packs (optional)
     - Handling Stripe webhooks
   - Use environment variables for Stripe keys.
   - On successful events:
     - Update user’s plan and credits.
