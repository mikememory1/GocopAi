DATABASE SCHEMA (SUPABASE)
==================================================

Create SQL migrations for at least:

- **chargers**
  - id uuid primary key default gen_random_uuid()
  - name text not null
  - location_lat double precision not null
  - location_lng double precision not null
  - network text
  - power_kw double precision
  - address text
  - region text
  - source text default 'ncr' -- 'ncr' | 'ocm' | 'user'
  - last_verified timestamptz
  - reliability_score double precision default 0
  - three_word_code text
  - is_active boolean default true

- **reports_chargers**
  - id uuid primary key default gen_random_uuid()
  - charger_id uuid references chargers(id) on delete cascade
  - status text check (status in ('working', 'broken')) not null
  - created_at timestamptz default now()
  - user_id uuid

- **traffic_reports**
  - id uuid primary key default gen_random_uuid()
  - type text check (type in ('accident', 'roadworks', 'closure', 'queue', 'other')) not null
  - description text
  - location_lat double precision not null
  - location_lng double precision not null
  - severity int
  - created_at timestamptz default now()
  - user_id uuid
  - is_active boolean default true

- **users**
  - id uuid primary key -- same as auth.users.id
  - email text unique not null
  - is_premium boolean default false
  - subscription_id text
  - created_at timestamptz default now()

- **fleets**
  - id uuid primary key default gen_random_uuid()
  - name text not null
  - contact_email text
  - created_at timestamptz default now()

- **fleet_members**
  - id uuid primary key default gen_random_uuid()
  - fleet_id uuid references fleets(id) on delete cascade
  - user_id uuid references users(id) on delete cascade
  - role text default 'driver'

- **regions**
  - id uuid primary key default gen_random_uuid()
  - name text not null
  - code text
  - created_at timestamptz default now()

- **charger_regions**
  - id uuid primary key default gen_random_uuid()
  - charger_id uuid references chargers(id) on delete cascade
  - region_id uuid references regions(id) on delete cascade

Implement basic Row Level Security (RLS) so users can only see/modify their own sensitive data where appropriate.

EDGE FUNCTIONS (SUPABASE)
==================================================

Implement at least:

1. **reliability** (Edge Function)
   - Triggered by DB webhook on INSERT into `reports_chargers`.
   - Fetch all reports for that charger.
   - Compute reliability_score = working / total (optionally weighted by recency).
   - Update `chargers.reliability_score` and `chargers.last_verified`.

2. **create-checkout-session** (Edge Function)
   - Accepts JSON: { user_id, email }.
   - Uses STRIPE_SECRET_KEY and STRIPE_PRICE_ID.
   - Creates Stripe Checkout session (subscription mode).
   - Returns JSON: { url }.

3. **stripe-webhook** (Edge Function)
   - Verifies Stripe webhook using STRIPE_WEBHOOK_SECRET.
   - Handles:
     - checkout.session.completed → set users.is_premium = true, store subscription_id.
     - customer.subscription.deleted → set users.is_premium = false.
   - Uses SUPABASE_SERVICE_ROLE_KEY to update users table.
